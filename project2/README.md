## 🏗️ Project Overview  
This project highlights my skills in **Power Query**, **Power Pivot**, and **interactive data visualization** using Excel. The goal was to clean and prepare complex data, create relationships between multiple tables, and design a dynamic dashboard that provides insights through slicers and pivot charts.

---

## 🔑 Key Features  
- **Power Query Transformations**  
  - Cleaned and prepared data by creating new columns, combining data, and removing inconsistencies.
  - Created a consolidated skills table to count the number of skills per job title.  
 ![data clean](../assests/data_clean_up.png)
![alt text](../assests/new_skills_table.png)

- **Data Modeling with Power Pivot**  
  - Built relationships between tables using a data model diagram to enable complex cross-table analysis.  

![alt text](../assests/data_diagram.png)

- **Interactive Pivot Dashboards**  
  - Designed pivot charts and tables that update dynamically with slicers.
  - Included slicers for country and skill selection that synchronize filters across all relevant sheets.

## 🌟 Conclusion & Reflection  
This project showcases my ability to handle complex data workflows using **Power Query** and **Power Pivot**. By transforming raw data and building relationships, I created a fully interactive dashboard that makes job and salary analysis intuitive and efficient.

Through this project, I honed my skills in data modeling, visualization, and cross-sheet interaction. Future improvements could include:
- Adding conditional formatting for visual emphasis on high/low salary insights.

- Migrating the dashboard to **Power BI** for even more powerful visualizations.
