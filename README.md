# 📊 Data Science Salary Insights (Excel Project)

This Excel-based project explores job market trends and salary insights in the Data Science field using real-world job posting data. It includes a functional salary calculator and analysis of factors like location, job type, and platform used for job listings.

## 🧠 Key Skills Demonstrated
- Advanced Excel functions and formulas
- Data cleaning and validation
- Pivot tables and cross-tab analysis
- Conditional formatting and drop-down validations
- Data visualization (charts, salary comparisons)

## 📂 What's Included
- **Data Sheet:** Cleaned dataset of 1,000+ data-related job postings with titles, salaries, job types, and required skills.
- **Salary Calculator:** Compare average salaries by country, role, and job type using Excel functions.
- **Platform Analysis:** Breakdown of job listing sources (e.g., LinkedIn, ZipRecruiter).

## 🛠️ Tools Used
- Microsoft Excel
- Functions: `VLOOKUP`, `IF`, `COUNTIF`, `AVERAGEIFS`, `Power Query`, `power pivot`
- Pivot Tables & Charts
- Data Validation

## 📈 Sample Use Case
Quickly assess salary trends for Data Engineers in the U.S. working full-time vs part-time, or identify which platforms list the most remote jobs.
